# Фокус — таймер и список задач

Мини-проект: таймер Помодоро (25/5/15 минут) и список задач.
Данные сохраняются в браузере (localStorage), счётчик сессий считается за каждый день.

**Технологии:** HTML, CSS, JavaScript (без библиотек и сборки).

**Демо:** https://toshi207.github.io/focus-timer/

## Запуск локально
Откройте `index.html` в браузере.
